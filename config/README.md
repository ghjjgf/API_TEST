# 全局配置

## 职责
提供接口测试默认服务地址、端口和超时配置。

## 目录内容
- `settings.py`：比对服务、检测服务、默认超时等常量。
- `__init__.py`：包标识。

## 入口
由 `function_test/conftest.py`、`business/support.py` 导入。

## 输入与输出
- 输入：读取当前环境下的默认主机和端口常量。
- 输出：不生成文件；为客户端提供连接参数。

## 依赖关系
被 `core`、`function_test`、`business` 间接依赖。

## 备注
环境地址需要变更时修改这里，避免在测试用例中重复硬编码。
